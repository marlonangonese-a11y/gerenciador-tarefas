## [0.1.0] — 2026-06-10

### Adicionado
- Estrutura inicial do projeto (frontend, backend, banco de dados).
- API REST com CRUD de tarefas e listagem de colunas (Node.js + Express).
- Quadro Kanban com arrastar e soltar entre colunas (HTML, CSS, JS).
- Scripts SQL de criação do banco, tabelas e dados iniciais (PostgreSQL).
- Pipeline de CI com GitHub Actions (testes, validação de sintaxe e SQL).
- Plano de Gerência de Configuração (docs/PGC.md).
- Manual técnico de instalação (docs/MANUAL_TECNICO.md).
- Modelos de issue e pull request para o fluxo de controle de mudanças.
